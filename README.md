# Insight Navigator

Quiero que se base en el dashboard institucional que diseñamos en Power BI, pero con una experiencia más fluida y moderna.

La página debe tener una pantalla principal minimalista, con tarjetas y gráficos que se expandan o se desglosen al hacer clic, evitando saturación visual.

Estructura sugerida:

Inicio / Panel Ejecutivo: muestra los KPIs principales (Puntaje Global, Evaluaciones, Mejor y Peor Evaluación, Indicadores Críticos) con animaciones suaves. Barra fija en la parte superior con:

Concesionaria ▼

Marca ▼

Ubicación ▼

Indicador ▼

Botón 🔄 “Limpiar filtros”

modulos de 

Benchmark y Ranking: sección con comparativas Maquinarias vs Competencia y ranking de locales, usando colores semáforo y barras dinámicas.

Mapa de Calor: visual interactiva donde el usuario puede pasar el cursor sobre cada local para ver detalles por indicador.

Preguntas Críticas: lista desplegable con las preguntas de menor cumplimiento y su porcentaje.

Comentarios del Evaluador: panel lateral que muestre resumen, recomendaciones y observaciones según el local seleccionado.

Fortalezas vs Oportunidades: tabla comparativa con íconos y colores corporativos.

Animaciones suaves y transiciones entre secciones.

Diseño responsive para escritorio y tablet.

Objetivo: que el usuario pueda explorar la información sin sentirse abrumado, con una navegación intuitiva y visualmente atractiva.
